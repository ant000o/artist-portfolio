# 🎨 Artist Portfolio

Personal project developed to practice and strengthen my knowledge in **HTML, CSS and JavaScript**.

The goal of this project is to build a modern, minimal and scalable portfolio website for an artist (my partner), inspired by contemporary artistic websites.

---

## 🚀 Purpose

* Improve semantic HTML structure
* Apply clean and scalable CSS architecture
* Strengthen JavaScript fundamentals
* Practice DOM manipulation and state handling
* Follow good development practices
* Prepare for future React projects

Although this project is primarily for learning purposes, it is being built with scalability in mind so it can eventually be used as a real portfolio website.

---

## 🛠️ Tech Stack

* HTML5 (semantic structure)
* CSS3 (modular architecture)
* JavaScript (Vanilla JS)
* JSON (dynamic gallery content)

---

## 📈 Development Process

I will be updating this repository regularly as I:

* Build new views (Home, Gallery, About, Commissions)
* Refactor code
* Improve accessibility
* Optimize structure and best practices

---

## 🎯 Long-term Vision

This project is part of my journey to become a fullstack developer.
Future iterations may include performance optimizations, animations improvements, and possibly a React refactor.
